##QUESTION 01
The foreign key (publisher = models.ForeignKey(Publisher, on_delete=models.CASCADE)) held by the book model points to the publisher model. This is because a publisher can have multiple books in the database and not the other way around. If the data entered was reversed the publisher would hold the foreign key and point to the book model, allowing for multiple publishers to be listed under one book title, but each publisher belongs to one book.

##QUESTION 02
The field of my choice for the Book model was a boolean True/False value used to display if the books in the catalog were held in print or not. Each book would default to having a printed version unless specified otherwise, I chose this field because this was my first thought when describing books in a catalog, at least that is what I would pay attention to when looking for books I wanted to physically read and hold. Additionally, I believe boolean fields are more efficient because of there only being two displayed results with the choice of a default option for the field which is very useful in this case.
While this is a more consistent option for the fact, if I had stored the same fact in a CharField I wouldn't lose anything but would have to rearrange my database to be able to display the same fact but as a CharField. I would have to create a loop to display if the book is digital only or not, but the main loss would be data consistency as there is a much more increased chance of error when using a CharField instead of a boolean in this case.
